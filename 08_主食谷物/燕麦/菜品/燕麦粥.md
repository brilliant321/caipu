# 燕麦粥

> 归属食材：[[燕麦]] ｜ 难度三档：初学 / 进阶 / 大厨

绵滑黏糯、麦香奶香，几分钟就能出锅，是快手又养胃的早餐。以下按「初学 / 进阶 / 大厨」三档给出做法，难度和讲究逐级递增。

> 计量参考：小勺 ≈ 5ml（茶匙），汤匙 ≈ 15ml，1 小勺盐 ≈ 5g、1 小勺糖 ≈ 5g。

---

## 初学版（目标：能做熟、不难吃）

**食材（1～2 人份）**

| 食材 | 用量 | 说明 |
|---|---|---|
| 即食 / 快熟燕麦片 | 50g | 快熟燕麦片口感更绵 |
| 清水或牛奶 | 400ml | 纯奶更香，也可水 + 奶各半 |
| 糖 / 蜂蜜 | 适量 | 甜口可选 |
| 盐 | 一丁点 | 提香（可选） |
| 配料（可选） | 红枣 / 葡萄干 / 香蕉等 | 按喜好加 |

**做法（点对点）**

**第 1 步 · 下锅**
1. 把燕麦片和液体（水 / 牛奶）一起倒进小锅。
2. 也可以先烧开水再下燕麦片，更不容易糊底。

**第 2 步 · 煮制**
3. 开中火煮到微微沸腾。
4. 立刻转**小火**，边煮边用勺子搅拌，约 3～5 分钟。
5. 煮到粥变浓稠、燕麦片软糯开花 → 关火前调味。

**第 3 步 · 调味出锅**
6. 关火前加糖或蜂蜜调味，撒上喜欢的配料，搅匀即可。
7. 咸口可以放一点点盐提香。

**新手翻车点**

- **粘锅糊底**：火太大、或没搅拌。煮开后一定转小火，并不断搅拌。
- **溢锅**：用纯牛奶煮、火又大，很容易溢。牛奶煮开要盯紧，小火 + 搅拌。
- **太稀像水 / 太稠像饭**：比例不对。燕麦片 : 液体约 **1 : 8** 起步，太稀就多煮一会、太稠就加一点热奶。
- **燕麦片没煮软**：用了生燕麦粒或钢切燕麦，这类要煮很久，新手先选「即食 / 快熟燕麦片」。

## 进阶版（关键技巧：比例 / 火候 / 出黏稠）

在初学版基础上，掌握下面四条，粥会更绵滑黏糯。

**做法（点对点）**

**第 1 步 · 液体比例**
1. 按 **1 : 8 到 1 : 10** 配液体：50g 燕麦配 400～500ml 水 / 奶；喜欢稀一点就 1 : 10，喜欢稠一点就 1 : 8。
2. 纯牛奶煮更香浓，但容易溢、也容易糊底；「水 + 奶各半」更稳，出锅前再补一点奶更香。

**第 2 步 · 先大火后小火**
3. **先大火把液体煮开**。
4. 再**转小火慢煮**，让燕麦片充分吸水、淀粉慢慢糊化（粥才黏糯不糊底）。

**第 3 步 · 搅拌出黏稠**
5. 边煮边搅拌，让淀粉均匀释放、粥体更绵滑，也防止糊底。
6. 搅拌到粥表面出现**细密的小泡、变得浓稠挂勺** → 差不多了。

**第 4 步 · 熬出「米油感」与配料**
7. **小火多搅、关火后盖上盖子焖 2 分钟**，会明显更绵滑浓稠。
8. 甜口搭配：红枣、葡萄干、香蕉、蓝莓、蜂蜜；咸口搭配：鸡蛋花、青菜碎、火腿丁、虾仁。

## 大厨版（专业细节与锅气）

追求「绵滑黏糯、麦香奶香、入口即化」。每一步都是细节。

**做法（点对点）**

**第 1 步 · 燕麦片选型**
1. **即食燕麦片**（热水一冲即熟）最省事，但口感略薄；**快熟燕麦片**（煮 3～5 分钟）口感最平衡；**钢切燕麦 / 生燕麦粒**最耐嚼，但要煮 20 分钟以上，风味最足。
2. 想要「米油感」更浓，可用**钢切燕麦 + 快熟燕麦各半**混搭，既有嚼劲又绵滑。

**第 2 步 · 液体处理**
3. 用牛奶煮时，**先小火把牛奶加热到温热、再下燕麦片**，边下边搅，燕麦不容易结块。
4. 煮开即转最小火，防止牛奶糊底和溢锅。
5. 也可先用水煮到燕麦开花、再关火拌入冷牛奶或淡奶油，奶香更浓且不破坏奶味（高温久煮会让牛奶发腥）。

**第 3 步 · 火候与焖煮**
6. 大火煮沸后转最小火，保持锅面微微冒泡即可，不停搅拌防糊。
7. 煮到浓稠后**关火盖盖焖 2 分钟**，让淀粉充分吸水，口感更绵。
8. 看到粥能「挂勺」、表面浮起一层细腻的黏稠层 → 好了。

**第 4 步 · 咸甜两派调味**
9. **甜口**：煮好后加蜂蜜（不要煮，高温会破坏蜂蜜营养），配香蕉片、蓝莓、肉桂粉，麦香更立体。
10. **咸口**：燕麦煮到浓稠后打入蛋花搅散，加青菜碎、火腿丁、一点白胡椒和盐，成咸鲜口味；或仿广式「皮蛋燕麦粥」加皮蛋和瘦肉。
