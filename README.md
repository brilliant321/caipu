# 烹饪储备库 · 使用说明

> 你的 AI 烹饪助手知识库。按「原料」组织菜品，每道菜给「初学 / 进阶 / 大厨」三档做法，并随你的实操反馈持续修订、锁定最佳方案。

## 目录结构
- `00_入门总纲` —— 刀工、火候、调味三大基本功
- `01_蔬菜` ～ `12_坚果干果` —— 按原料类别分的 12 个大目录，每个大目录下再细分具体食材
- `20_复盘日志` —— 记忆库：每次实操的反馈、修订与锁定记录
- `_scripts` —— 内部生成脚本（可忽略）

## 两种检索方式
1. **报菜名 / 报食材**：直接告诉我菜名或食材，我找到菜谱后把完整三档做法加载出来给你看，并用 **VS Code 打开**该菜谱文件（多道菜并列分屏）。
2. **报现有原料**：把你手头的原料告诉我，我优先推荐「现有原料就能做」的菜，再推荐「需补购原料」的菜（并说明要买什么），推荐出的菜谱同样用 VS Code 打开。

## 口味与忌口
把你的忌口、口味偏好告诉我，我会据此优先推荐；没说的话，默认按大众家常口味处理。

## 三档难度
每道菜分三档做法：
- **初学**：步骤少、容错高，先保证「能做熟、不难吃」。
- **进阶**：讲关键技巧（火候、切法、调味配比）。
- **大厨**：专业级细节与锅气，追求口感与风味层次。

## 记忆库机制（反馈 → 修订 → 锁定）
1. 你按某份做法做完 → 告诉我哪里好、哪里翻车。
2. 我据此修改步骤，直到你说「最佳」。
3. 锁定当前方案，写入该菜品文件里的「🔒 已锁定最佳方案」——最佳方案不唯一，同一道菜可同时保留多个（不同口味 / 场景 / 火候）。
4. 以后再点同一道菜：优先给锁定版，再附其他方案（创新口味、变体等）。
