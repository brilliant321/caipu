# 皮蛋豆腐

> 归属食材：[[皮蛋]] ｜ 难度三档：初学 / 进阶 / 大厨

嫩豆腐滑嫩、皮蛋 Q 弹，浇上咸鲜带酸的凉拌汁，清爽开胃，几分钟就能上桌的经典凉菜。以下按「初学 / 进阶 / 大厨」三档给出做法，难度和讲究逐级递增。

> 计量参考：小勺 ≈ 5ml（茶匙），汤匙 ≈ 15ml，1 小勺盐 ≈ 5g、1 小勺糖 ≈ 5g。

---

## 初学版（目标：能做熟、不难吃）

**食材（2 人份）**

| 食材 | 用量 | 说明 |
|---|---|---|
| 内酯豆腐（嫩豆腐） | 1 盒（约 300g） | 越嫩越好 |
| 皮蛋 | 2 个 | 切丁 |
| 生抽 | 2 汤匙 | 咸味主来源 |
| 香醋 | 1 汤匙 | 提酸爽 |
| 香油 | 1/2 汤匙（或几滴） | 增香 |
| 白糖 | 1/2 小勺 | 提鲜 |
| 蒜 | 2 瓣（切末） | 增香 |
| 姜 | 1 小片（切末） | 去皮蛋碱味、去腥 |
| 小葱 | 1 根（切葱花） | 出锅撒 |
| 小米椒 | 1 个（切圈，可选） | 提辣 |

**做法（点对点）**

**第 1 步 · 处理豆腐**
1. 内酯豆腐盒底部四角各剪一个小口。
2. 倒扣在盘里，轻拍盒底让整块豆腐完整滑出。
3. 用刀在豆腐上横竖划几刀切成小块。看到豆腐完整、没有碎成一滩 → 处理好了。

**第 2 步 · 处理皮蛋**
4. 皮蛋剥壳，用刀切成小丁（刀蘸点水或抹油不粘）。看到蛋黄凝固、好切 → 切好了。

**第 3 步 · 调汁**
5. 小碗里放蒜末、姜末、生抽、香醋、白糖、香油，再加 1~2 汤匙凉开水。
6. 搅匀到糖完全溶解、汁水咸酸平衡 → 汁调好了。

**第 4 步 · 装盘浇汁**
7. 把皮蛋丁铺在豆腐上。
8. 均匀淋上调好的汁，撒葱花和小米椒圈，上桌前轻轻拌一下（或不拌，吃时再拌）。

**第 5 步 · 完成**
9. 静置 2 分钟入味即可开吃。

**新手翻车点**

- **豆腐碎了**：脱模太暴力或没剪排气口。盒子四角剪口 + 倒扣轻拍，豆腐就能完整滑出。
- **汁太咸**：生抽倒太多。生抽为主、香醋提味，先少倒、拌匀尝一口再补。
- **皮蛋切得烂**：刀太钝或蛋黄溏心太软。刀蘸凉水再切，或用细线（牙线）勒，切口更整齐。
- **姜味太冲**：姜末切太粗。姜去皮后尽量切细，或只取姜汁，去腥不抢味。

## 进阶版（关键技巧：去豆腥 / 皮蛋定型 / 料汁 / 姜汁）

在初学版基础上，掌握下面四条，成品质感会更清爽。

**做法（点对点）**

**第 1 步 · 豆腐去豆腥**
1. 内酯豆腐脱模后，放进开水里烫 30 秒（或上锅蒸 3 分钟）。
2. 捞出沥干再切。看到豆腐更嫩、豆腥味明显减轻 → 可以了。

**第 2 步 · 皮蛋先蒸定型**
3. 溏心皮蛋难切时，整个带壳蒸 5~8 分钟。看到蛋黄凝固、更好切块 → 蒸好了（也不容易弄得黑乎乎）。

**第 3 步 · 万能凉拌汁**
4. 生抽 2 : 香醋 1 : 香油 0.5 : 糖 0.5，加 1~2 汤匙凉开水稀释。
5. 喜欢辣加辣椒油 / 老干妈，喜欢蒜香多放蒜末，喜欢麻香加几滴花椒油。

**第 4 步 · 姜汁代替姜末**
6. 介意姜末口感的人，把姜擦成泥挤出姜汁滴进料汁——去皮蛋的碱味和腥味，又吃不到姜粒。

## 大厨版（专业细节与锅气）

追求「豆腐冰凉滑嫩、皮蛋溏心香糯、料汁层次分明」。每一步都是细节。

**做法（点对点）**

**第 1 步 · 皮蛋切瓣摆盘**
1. 皮蛋对半再对半切成月牙瓣，沿盘边围一圈。
2. 豆腐放中间，皮蛋的「溏心」朝外露出，摆盘更精致。

**第 2 步 · 热油激香（可选）**
3. 把蒜末、小米椒圈、葱花铺在豆腐表面。
4. 烧一勺热油（约 2 汤匙，烧到冒烟）浇上去「滋」一下，蒜香辣香被激发，再淋凉拌汁。

**第 3 步 · 料汁分层下**
5. 先淋咸鲜的酱油汁，再点香醋和香油，最后撒糖，让各味在拌的时候才融合，口口有层次。

**第 4 步 · 冰镇提鲜**
6. 上桌前把豆腐和皮蛋放冰箱冷藏 10 分钟（或豆腐一直冷藏保存），冰凉的口感更清爽解腻，夏天尤佳。
