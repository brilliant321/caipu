# 卤鹌鹑蛋

> 归属食材：[[鹌鹑蛋]] ｜ 难度三档：初学 / 进阶 / 大厨

鹌鹑蛋煮好后敲裂蛋壳，放进香料卤汁里慢煮、浸泡，蛋白 Q 弹入味、蛋黄绵香，冷热都好吃的下酒小菜和追剧零食。以下按「初学 / 进阶 / 大厨」三档给出做法，难度和讲究逐级递增。

> 计量参考：小勺 ≈ 5ml（茶匙），汤匙 ≈ 15ml，1 小勺盐 ≈ 5g、1 小勺糖 ≈ 5g。

---

## 初学版（目标：能做熟、不难吃）

**食材（约 30 个 / 2 人份）**

| 食材 | 用量 | 说明 |
|---|---|---|
| 鹌鹑蛋 | 30 个（约 300g） | 洗净 |
| 生抽 | 3 汤匙 | 咸味主来源 |
| 老抽 | 1 汤匙 | 上色 |
| 冰糖 | 2 小勺（约 10g） | 回甘 |
| 盐 | 1 小勺（约 5g） | 调味 |
| 八角 | 2 个 | 增香 |
| 桂皮 | 1 小段 | 增香 |
| 香叶 | 2 片 | 增香 |
| 花椒 | 1 小勺 | 增香（可选） |
| 姜 | 3 片 | 去腥 |
| 清水 | 约 500ml | 没过鹌鹑蛋 |

**做法（点对点）**

**第 1 步 · 煮蛋**
1. 鹌鹑蛋洗净后冷水下锅，水要没过蛋。
2. 开中火煮，水开后转小火再煮 4~5 分钟。看到蛋白全熟、蛋黄刚凝固 → 煮好了。

**第 2 步 · 过凉处理**
3. 捞出立刻放进冷水里泡 2 分钟降温。
4. 想更入味就剥壳；不想剥壳就用勺子背把每颗蛋壳轻轻敲出裂纹（裂纹多入味快，别敲碎）。看到壳上布满细裂纹、或已剥净 → 处理好了。

**第 3 步 · 调卤汁**
5. 另起锅倒入清水，加八角、桂皮、香叶、花椒、姜片、生抽、老抽、冰糖、盐。
6. 大火烧开后转小火煮 5 分钟出香味。闻到香料味、汤汁呈深褐色 → 卤汁好了。

**第 4 步 · 卤制**
7. 放入处理好的鹌鹑蛋，保持小火煮 15~20 分钟。
8. 中途轻轻翻动让上色均匀。

**第 5 步 · 浸泡入味**
9. 关火后别急着捞出，让鹌鹑蛋在卤汁里泡至少 1 小时（过夜更入味）。
10. 吃之前捞出即可。

**新手翻车点**

- **蛋煮裂或爆开**：开水下锅或火太大。一定冷水下锅、水开后转小火，避免蛋壳骤然受热爆裂。
- **不入味**：没敲裂纹、没浸泡或卤的时间太短。敲裂 + 关火浸泡是入味的关键。
- **太咸 / 太淡**：卤汁调味没尝。卤汁要比直接吃略咸一点，成品才刚好；先尝卤汁再下蛋。
- **剥壳困难**：煮好没立刻过冷水。过冷水的一瞬间蛋会收缩，壳就好剥。

## 进阶版（关键技巧：煮蛋 / 入味 / 卤汁 / 浸泡）

在初学版基础上，掌握下面四条，成品味道会更足。

**做法（点对点）**

**第 1 步 · 冷水下锅、小火煮**
1. 鹌鹑蛋比鸡蛋壳更薄、更易裂，务必冷水下锅。
2. 水开后转小火煮 4~5 分钟（喜欢溏心可缩短）。
3. 捞出立刻进冷水，看到蛋白收缩、蛋壳好剥 → 煮好了。

**第 2 步 · 入味三件套**
4. 新手推荐「敲裂纹」：不剥壳，用勺背敲出裂纹，保留蛋壳让卤汁慢慢渗进去，蛋白更完整。
5. 或**剥壳**（入味最快，但蛋白直接泡卤汁会稍硬）。
6. 或剥壳后在表面浅划 2~3 刀。

**第 3 步 · 卤汁配比**
7. 生抽 3 : 老抽 1 的比例上色，冰糖给回甘。
8. 香料用八角 + 桂皮 + 香叶 + 花椒打底；想要茶叶蛋风味，可加 1 小撮红茶或乌龙。

**第 4 步 · 浸泡比煮更关键**
9. 卤 15~20 分钟只是「煮熟入味」。
10. 真正入味靠关火后浸泡：室温泡 1 小时起步，冷藏泡过夜味道最好。

## 大厨版（专业细节与锅气）

追求「蛋白紧实 Q 弹、酱色红亮、越嚼越香」。每一步都是细节。

**做法（点对点）**

**第 1 步 · 留老卤水**
1. 卤汁用完后别倒，滤掉香料渣、撇去浮沫。
2. 烧开晾凉装进密封盒冷藏，就是「老卤」。下次卤时补一点盐和香料，越用越香。

**第 2 步 · 啤酒卤 / 糖色卤**
3. 追求红亮色泽：先用少量油把冰糖炒成枣红色糖色，再加水调卤汁。
4. 或用啤酒代替一半清水（麦香 + 微甜），成色红亮、回甘明显。

**第 3 步 · 低温慢卤 + 浸泡一夜**
5. 煮蛋后用最小火慢卤 20~30 分钟，让蛋白慢慢收紧。
6. 再关火浸泡过夜，蛋白会变得紧实 Q 弹、越嚼越香，接近「铁蛋」的紧实感。

**第 4 步 · 出品细节**
7. 上桌前把卤蛋捞起沥干，表面刷一层卤汁或点几滴香油。
8. 撒白芝麻或葱花增香；冷吃更有嚼劲，热吃更软糯。
