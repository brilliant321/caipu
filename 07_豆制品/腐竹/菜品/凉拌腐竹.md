# 凉拌腐竹

> 归属食材：[[腐竹]] ｜ 难度三档：初学 / 进阶 / 大厨

腐竹吸满酸辣料汁，配黄瓜、木耳脆爽开胃，是一道零油烟、怎么拌都好吃的凉菜。关键是泡发和「攥干水」，让腐竹吃味又柔韧。

> 计量参考：小勺 ≈ 5ml（茶匙），汤匙 ≈ 15ml，1 小勺盐 ≈ 5g、1 小勺糖 ≈ 5g。

---

## 初学版（目标：能泡软、拌入味）

**食材（2~3 人份）**

| 食材 | 用量 | 说明 |
|---|---|---|
| 干腐竹 | 3~4 根（约 60g） | 泡发后会膨胀，别抓太多 |
| 黄瓜 | 1 根 | 拍碎或切丝，解腻 |
| 蒜 | 3 瓣 | 切末，凉拌的灵魂 |
| 生抽 | 2 汤匙 | |
| 香醋 | 1 汤匙 | 或陈醋 |
| 白糖 | 1 小勺 | |
| 香油 | 1 小勺 | |
| 辣椒油 | 1 小勺（可选） | 不吃辣可不放 |
| 盐 | 少许 | 最后补味 |

**做法（点对点）**

**第 1 步 · 泡发**
1. 干腐竹掰成小段，放进温水（约 40℃，不烫手）里泡 1~2 小时。
2. 泡到没有硬芯、捏起来里外都软 → 泡好。着急用可以换几次温水，缩短时间。

**第 2 步 · 焯水**
3. 锅里烧开水，下泡好的腐竹煮约 1 分钟（泡透的煮短一点）。
4. 捞出立刻过凉水。

**第 3 步 · 攥干水（关键）**
5. 把腐竹捞出来，用手轻轻攥掉多余水分——水分不攥干，料汁会被稀释、味道进不去。

**第 4 步 · 配菜**
6. 黄瓜拍一下再切段，蒜切末。

**第 5 步 · 调汁**
7. 小碗里放蒜末、生抽、香醋、白糖、香油、辣椒油，搅到糖化开。

**第 6 步 · 拌匀**
8. 腐竹、黄瓜放进大碗，倒料汁，翻拌均匀。
9. 腌 5 分钟再吃，更入味。

**新手翻车点**

- **腐竹有硬芯**：泡的时间不够或用冷水硬泡。用温水泡 1~2 小时，掰断看中间没有白心才算好。
- **味道淡 / 水汪汪**：没攥干水。焯水后一定要攥掉多余水分再拌。
- **腐竹煮烂没嚼劲**：焯太久。泡透的腐竹煮 1 分钟就够，捞出过凉水保持柔韧。
- **蒜味太冲**：蒜末可先拌进去腌一会儿，或怕冲就减量、多放香油。

## 进阶版（关键技巧：泡发 / 焯水 / 料汁 / 配菜）

在初学版基础上，掌握下面四条，成品质感会上一个台阶。

**做法（点对点）**

**第 1 步 · 泡发三法**
1. 时间充裕用冷水泡 3~4 小时（口感最柔韧）。
2. 赶时间用温水 40℃ 加少许盐泡 1~2 小时。
3. 千万别用开水，外面烂了里面还是硬的。

**第 2 步 · 焯水时间**
4. 冷水泡的腐竹焯 30~60 秒；温水泡的焯 10~30 秒即可。
5. 焯完立刻过凉水，口感更筋道。

**第 3 步 · 料汁的层次**
6. 生抽 2 + 香醋 1 + 糖 1 小勺是基础酸甜底。
7. 想香就加一勺热油泼过的蒜末（蒜末 + 白芝麻 + 辣椒面，淋热油激香），这是凉拌菜提香的核心。

**第 4 步 · 配菜**
8. 木耳、胡萝卜丝提前焯熟，和黄瓜一起拌，颜色和口感都更丰富。
9. 熟花生米最后撒，保持酥脆。

## 大厨版（专业细节）

**做法（点对点）**

**第 1 步 · 选腐竹**
1. 挑颜色淡黄、有自然豆香、掰断时干脆的；发黑或黏手的是受潮变质的，别用。

**第 2 步 · 泡到「八成软」再焯**
2. 泡到八九成软（中心还有一点点硬）就下锅焯，焯完刚好全软，口感最筋道、不烂。

**第 3 步 · 料油定味**
3. 冷油下几粒花椒、葱段，小火炸到葱变焦黄。
4. 捞出料渣，趁热泼在蒜末辣椒面上——这勺「料油」是凉拌腐竹香味的来源。

**第 4 步 · 先拌后腌**
5. 料汁浇上去，先拌匀。
6. 冷藏腌 10~15 分钟，让腐竹把汁吸进去。
7. 上桌前再撒花生米和香菜，保持脆感和颜色。
