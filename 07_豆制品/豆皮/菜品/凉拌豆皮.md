# 凉拌豆皮

> 归属食材：[[豆皮]] ｜ 难度三档：初学 / 进阶 / 大厨

豆皮柔韧爽滑、不腻口，配黄瓜丝和酸辣料汁，香辣开胃又下饭。关键是焯水去豆腥、挤干水，让料汁挂得住。

> 计量参考：小勺 ≈ 5ml（茶匙），汤匙 ≈ 15ml，1 小勺盐 ≈ 5g、1 小勺糖 ≈ 5g。

---

## 初学版（目标：能做熟、酸辣开胃）

**食材（2 人份）**

| 食材 | 用量 | 说明 |
|---|---|---|
| 豆皮（千张/豆腐皮） | 1~2 张（约 150g） | 干的用温水先泡软，鲜的直接用 |
| 黄瓜 | 半根 | 切丝 |
| 蒜 | 3 瓣 | 切末 |
| 香菜 | 1 小把（可选） | 切段 |
| 生抽 | 2 汤匙 | |
| 香醋 | 1 汤匙 | |
| 白糖 | 1 小勺 | |
| 辣椒油 | 1 小勺 | 不吃辣减量 |
| 香油 | 1 小勺 | |
| 熟白芝麻 | 1 小撮（可选） | |

**做法（点对点）**

**第 1 步 · 切豆皮**
1. 干豆皮用温水泡软（约 10 分钟），鲜豆皮直接冲一下。
2. 叠起来切成约 0.5cm 宽的丝。

**第 2 步 · 焯水**
3. 水烧开后下豆皮丝，焯约 1 分钟，去掉豆腥味、口感更柔韧。
4. 捞出过凉水。

**第 3 步 · 挤干水**
5. 把豆皮捞出来轻轻挤掉水分（别挤烂），水多会冲淡味道。

**第 4 步 · 配菜**
6. 黄瓜切丝，蒜切末，香菜切段。

**第 5 步 · 调汁**
7. 碗里放蒜末、生抽、香醋、白糖、辣椒油、香油，搅匀。

**第 6 步 · 拌匀**
8. 豆皮丝、黄瓜丝、香菜放进大碗，倒料汁翻拌均匀。
9. 撒白芝麻，腌几分钟再吃。

**新手翻车点**

- **豆皮有豆腥 / 发硬**：没焯水或焯太短。水开焯 1 分钟再投凉，去腥又柔韧。
- **味道淡**：没挤干水。焯完的水分不挤掉，料汁会被稀释。
- **豆皮切成一坨**：切之前把豆皮摊平、叠整齐再切，丝才均匀。
- **太辣 / 太酸**：辣椒油和醋先少放，拌匀尝过再加。

## 进阶版（关键技巧：选豆皮 / 焯水 / 热油料汁 / 配菜）

在初学版基础上，掌握下面四条，成品质感会上一个台阶。

**做法（点对点）**

**第 1 步 · 选豆皮**
1. 「豆腐皮/千张」偏韧、豆香浓；「油豆皮」更薄更滑，焯水时间要更短。
2. 干豆皮一定先温水泡软再切。

**第 2 步 · 焯水投凉**
3. 水里加一点盐和几滴油，焯出的豆皮更爽滑。
4. 焯完立刻投凉水，口感更筋道。

**第 3 步 · 热油激香**
5. 蒜末 + 辣椒面 + 白芝麻放碗里，烧一勺热油泼上去，激出香味。
6. 再加生抽、醋、糖、蚝油，这是凉拌豆皮香味的来源。

**第 4 步 · 配菜**
7. 黄瓜丝、胡萝卜丝（焯熟）、洋葱丝、炸花生米、粉丝都可以加，让口感和颜色更丰富。

## 大厨版（专业细节）

**做法（点对点）**

**第 1 步 · 刀工**
1. 豆皮叠成整齐的条再切细丝，粗细均匀，拌的时候才挂料汁、吃口一致。

**第 2 步 · 焯水控时**
2. 千张焯 1 分钟、油豆皮焯 20~30 秒，时间长了会软烂没嚼劲。

**第 3 步 · 料油提香**
3. 冷油下花椒、干辣椒段，小火炸香后捞出，趁热泼在蒜末上。
4. 再加生抽、陈醋、糖、少许花椒油，酸辣麻香层次足。

**第 4 步 · 拌后静置**
5. 拌好静置 5~10 分钟，让豆皮吸味。
6. 上桌前再撒花生米（保持酥脆）和香菜（保持颜色）。
