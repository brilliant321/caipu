# 蒜蓉空心菜

> 归属食材：[[空心菜]] ｜ 难度三档：初学 / 进阶 / 大厨

最家常的绿叶快炒菜，蒜香浓、菜杆脆嫩。成败全看火够不够大、手够不够快——空心菜一炒久就出水发黄。

> 计量参考：小勺 ≈ 5ml（茶匙），汤匙 ≈ 15ml，1 小勺盐 ≈ 5g、1 小勺糖 ≈ 5g。

---

## 初学版（目标：能做熟、不难吃）

**食材（2 人份）**

| 食材 | 用量 | 说明 |
|---|---|---|
| 空心菜 | 1 把（约 400g） | 挑茎细嫩、叶子不发黄的 |
| 大蒜 | 5~6 瓣 | 剁蒜末，蒜多才香 |
| 盐 | 1/2 小勺（约 2g） | 调味 |
| 食用油 | 2 汤匙（约 20ml） | 油别太少，空心菜吸油才嫩 |
| 干辣椒 | 2~3 个 | 可选，不吃辣可不加 |
| 蚝油 | 1/2 汤匙 | 可选，提鲜 |

**做法（点对点）**

**第 1 步 · 洗菜切段**
1. 空心菜掐掉老根和发黄的叶子，整把放清水里洗 2~3 遍，洗到水清。
2. 捞出甩干水，切成约 5cm 长的段，茎和叶大致分开堆——茎难熟、叶好熟，分开方便先后下锅。

**第 2 步 · 备蒜**
3. 大蒜拍扁去皮，剁成蒜末，装小碗放灶台边。

**第 3 步 · 大火快炒**
4. 锅烧热倒油，转大火，油刚冒轻烟 → 下蒜末（怕辣这时一起下干辣椒段）。
5. 快速翻炒约 10 秒，闻到蒜香、蒜末还没焦黄 → 先下空心菜茎，炒约 20 秒。
6. 看到茎变绿、微微变软 → 下叶子，继续大火翻炒约 30 秒。
7. 叶子变软、颜色变深绿、锅底没有多余的水 → 加盐（要提鲜就这时加蚝油），翻炒几下关火出锅。

**新手翻车点**

- **出水变汤、菜发黄**：火太小或炒太久。空心菜要全程大火、快炒，叶子一软就出锅。
- **茎还是生的、叶已烂**：茎叶一起下锅。记住茎先下、叶后下，熟得才均匀。
- **蒜炒糊发苦**：蒜末在热油里别久炒，闻到香味就下菜，糊了会发苦。
- **洗好没甩干就下锅**：菜上带太多水，一下锅就变成「煮菜」。洗完一定甩干再炒。

## 进阶版（关键技巧：茎叶分开下锅 / 蒜分两次 / 大火快炒）

在初学版基础上，掌握下面几点成品质感会上台阶。

**做法（点对点）**

**第 1 步 · 茎叶分时下锅**
1. 茎段先下锅炒约 20 秒，等它半熟、颜色转深绿，再下叶子。
2. 叶子一下锅就翻，让它全裹上油，炒 20~30 秒就软。

**第 2 步 · 蒜分两次放（金银蒜）**
3. 一半蒜末先下锅爆香，炒出底香。
4. 出锅前再撒剩下的一半蒜末，翻两下就关火——生蒜的冲香和熟蒜的醇香叠在一起，蒜味更立体。

**第 3 步 · 火候与出水**
5. 全程最大火，油烧到微微冒烟再下菜；炒到叶子刚软、锅底还没出水 → 立刻调味出锅。
6. 若实在偏干，可沿锅边淋 1 汤匙清水，别直接倒菜上，防止降温出汤。

## 大厨版（专业细节与锅气）

追求翠绿、脆爽、锅气足的粤式小炒质感。

**做法（点对点）**

**第 1 步 · 热油热水撞锅**
1. 锅烧到很热，倒油后立刻下蒜末，同时沿锅边淋一小勺热水——热油遇热水会「嗤」地窜起蒸汽，高温蒸汽把空心菜瞬间烫熟，锁住翠绿。
2. 下空心菜茎，大火翻两下，再下叶，全程保持最大火，动作要快。

**第 2 步 · 蒜末炼香**
3. 蒜末提前分三份：下锅爆香一份、翻炒中途加一份、出锅前撒一份，蒜香层层递进。

**第 3 步 · 调味从简**
4. 只放盐（顶多加一点点蚝油），不放生抽——生抽色重，会把翠绿染暗。
5. 出锅前沿锅边点几滴油提亮，颠两下装盘，锅气（高温快炒那股焦香）凉了就散，趁热上桌。
