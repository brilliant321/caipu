# 凉拌秋葵

> 归属食材：[[秋葵]] ｜ 难度三档：初学 / 进阶 / 大厨

焯水加浇汁的一盘清爽凉菜，成败在「先整根煮、煮完再切、煮完过凉」——这样秋葵的黏液不流失、口感才滑嫩爽脆。

> 计量参考：小勺 ≈ 5ml（茶匙），汤匙 ≈ 15ml，1 小勺盐 ≈ 5g、1 小勺糖 ≈ 5g。

---

## 初学版（目标：能拌、爽口、不难吃）

**食材（2 人份）**

| 食材 | 用量 | 说明 |
|---|---|---|
| 秋葵 | 约 250g（15~20 根） | 选个头小、表面绒毛挺的嫩秋葵 |
| 大蒜 | 3 瓣 | 切蒜末 |
| 小米椒 | 1~2 个 | 切圈（可选，不吃辣可不放） |
| 生抽 | 2 汤匙（约 30ml） | 咸鲜底味 |
| 香醋（或陈醋 / 米醋） | 1~2 汤匙（约 15~30ml） | 酸味来源 |
| 蚝油 | 1 小勺（约 5ml） | 提鲜（可选） |
| 白糖 | 1/2 小勺（约 2g） | 中和酸辣 |
| 香油 | 1 小勺（约 5ml） | 提香（可选） |
| 食用油 | 2 汤匙（约 20ml） | 最后热油激香用 |
| 盐 | 1 小撮 | 焯水用 |

**做法（点对点）**

**第 1 步 · 洗秋葵**
1. 秋葵放进清水里，加一小撮盐，用手搓洗表面小绒毛，冲净沥干——绒毛里藏脏，搓一下更干净。
2. 先不去蒂——带着蒂整根煮，黏液才不会跑进水里。

**第 2 步 · 焯水**
3. 锅里烧一锅水，水开后加一小撮盐、滴几滴油（盐让秋葵有底味，油让它保持翠绿）。
4. 下秋葵，保持中大火煮约 2 分钟，看到颜色变成鲜亮的深绿、用筷子夹起一根会软软垂下 → 立刻捞出。

**第 3 步 · 过凉**
5. 捞出的秋葵立刻放进冰水（或凉白开）里泡 1~2 分钟，泡到完全凉透 → 捞出沥干。一热一冷，口感更脆、颜色不黄。

**第 4 步 · 切秋葵**
6. 切掉蒂部硬头，对半切开（或切段）摆盘。切出的黏液滑滑的属正常，留着才好吃。

**第 5 步 · 调汁浇上**
7. 蒜末、生抽、香醋、蚝油、白糖、香油（和切圈的小米椒）放进小碗拌匀，尝一口，调到咸酸平衡。
8. 把汁淋在秋葵上，拌匀就能吃。

**新手翻车点**

- **秋葵发黄、煮过头**：焯得太久。水开下锅、约 2 分钟、颜色变深绿就捞。
- **口感软烂、黏液全跑到水里**：先切后煮。记住「先整根煮、煮完再切」。
- **不入味**：煮前没放盐、或者没切开就浇汁。煮时加盐打底，切开再淋汁，汁才会渗进缝隙。
- **太咸太酸**：生抽、蚝油本身都咸，先把汁调在小碗里尝过再浇，盐最后看情况补。

## 进阶版（关键技巧：焯水火候 / 冰水过凉 / 先煮后切保黏液 / 凉拌汁配比）

在初学版基础上，掌握下面几条，成品质感会上一个台阶。

**做法（点对点）**

**第 1 步 · 焯水火候看颜色**
1. 2 分钟是参考，嫩秋葵 90 秒就够、老秋葵可到 3 分钟。判断标准：颜色由草绿变深绿发亮、筷子能轻松扎透根部就捞出。

**第 2 步 · 冰水过凉要「凉透」**
2. 过凉一定要泡到完全凉透，半温不凉时秋葵还会被余温继续焖熟、变软。冰水比凉白开更脆。

**第 3 步 · 先煮后切保黏液**
3. 秋葵切开或久煮会流出黏滑的汁液（它自带的天然胶质，不坏、还对肠胃友好）。整根带蒂煮、煮完再切，黏液留在秋葵里，口感才滑嫩。

**第 4 步 · 凉拌汁先小碗调好**
4. 记一个「万能凉拌汁」比例：生抽 2 : 香醋 1 : 蚝油 0.5 : 糖少许，先在小碗里调匀、尝过味再浇，盐最后看情况补。

## 大厨版（专业细节与响油）

追求「翠绿发亮、滑嫩爽脆、蒜香激鼻」。

**做法（点对点）**

**第 1 步 · 挑嫩秋葵**
1. 用指甲轻掐秋葵根部，能留下印子 = 嫩；掐不动、捏着发硬 = 老，口感差。

**第 2 步 · 响油激香**
2. 摆好盘的秋葵上铺蒜末、小米椒圈。
3. 烧一勺油到微微冒烟（七八成热），「刺啦」泼上去——热油瞬间激出蒜香和辣香，比直接拌进去香得多。

**第 3 步 · 顺序别反**
4. 先淋料汁、再泼热油——料汁给味道、热油激香气，顺序反了香气会打折扣。

**第 4 步 · 冷藏入味**
5. 拌好盖保鲜膜，冷藏 10 分钟再吃——凉了更爽口，味道也更均匀。
