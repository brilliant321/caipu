# 清炒山药木耳

> 归属食材：[[山药]] ｜ 难度三档：初学 / 进阶 / 大厨

清淡爽脆的养胃小炒，成败在「山药削皮防手痒、切好泡水防变黑」——处理对了，白嫩的山药配黑木耳，清爽不腻。

> 计量参考：小勺 ≈ 5ml（茶匙），汤匙 ≈ 15ml，1 小勺盐 ≈ 5g、1 小勺糖 ≈ 5g。

---

## 初学版（目标：能做熟、爽脆、不难吃）

**食材（2 人份）**

| 食材 | 用量 | 说明 |
|---|---|---|
| 山药 | 1 根（约 300g） | 铁棍山药口感更绵，脆山药更爽口，按喜好选 |
| 干木耳 | 10g（泡发后约 100g） | 提前用温水泡发 |
| 胡萝卜 | 半根 | 切片配色（可选） |
| 蒜 | 2 瓣 | 切片 |
| 小葱 | 1 根 | 切段，出锅前撒 |
| 盐 | 约 1 小勺（5g） | 分次放 |
| 生抽 | 1 小勺（约 5ml） | 提鲜（可选，放多会染色） |
| 白醋 | 几滴 | 泡山药防黑用，炒时也可滴几滴 |
| 食用油 | 2 汤匙（约 20ml） | 分两次用 |

**做法（点对点）**

**第 1 步 · 泡木耳**
1. 干木耳放进温水里泡发约 20~30 分钟，泡软后撕成小朵、去掉根部的硬蒂，洗净——木耳现泡现用，泡太久会坏。

**第 2 步 · 处理山药（防手痒）**
2. 先戴一次性手套（或手上套个保鲜袋），再给山药削皮——山药黏液沾手会痒，别让皮肤直接碰。
3. 削好的山药切成约 2mm 的薄片（或菱形片），立刻放进加了几滴白醋的清水里泡着，防止变黑、去掉表面黏液。

**第 3 步 · 焯水**
4. 锅里烧水，水开后下山药片和木耳，烫约 1 分钟，看到山药由硬变微透明 → 捞出沥干。焯水就是放滚水里短烫一下，蔬菜开水下锅保色保脆。

**第 4 步 · 炒**
5. 锅烧热倒 2 汤匙油，下蒜片爆香约 10 秒，闻到蒜香 → 下胡萝卜片（若用）翻炒约 30 秒。
6. 倒山药和木耳，转大火翻炒约 1~2 分钟，太干就沿锅边淋一小勺清水防糊。
7. 加盐、生抽，沿锅边滴几滴白醋，撒葱段，翻匀；夹一片尝：熟了仍脆 → 关火出锅。

**新手翻车点**

- **削山药手痒**：没戴手套。山药黏液里含刺激皮肤的物质，一定戴手套或套保鲜袋；已经痒了，用白醋搓洗、再用热水冲能缓解。
- **山药变黑**：切好没泡水。切好立刻泡进加了几滴醋的清水里。
- **炒糊底**：山药含淀粉容易粘锅。火别太干，太干时沿锅边淋一点清水。
- **炒烂不脆**：炒太久。焯过水的山药下锅 1~2 分钟、断生就出锅。

## 进阶版（关键技巧：泡醋水防黑 / 焯水保脆 / 保持洁白 / 勾薄芡）

在初学版基础上，掌握下面几条，成品质感会上一个台阶。

**做法（点对点）**

**第 1 步 · 泡醋水防黑**
1. 清水里加几滴白醋泡山药——酸能抑制氧化，山药切好泡在里面就不会变黑。

**第 2 步 · 焯水锁脆**
2. 山药、木耳先焯水，下锅炒制时间就短，口感更脆、颜色更好。

**第 3 步 · 保持洁白**
3. 想让山药白净，就别放老抽、生抽（会染色），只用盐调味，出锅前滴几滴白醋提亮去生味。

**第 4 步 · 勾薄芡（可选）**
4. 出锅前淋一点水淀粉（淀粉 + 冷水调匀），让汤汁变浓、均匀挂在山药上，更入味。

## 大厨版（专业细节与锅气）

追求「洁白脆嫩、清亮不糊、出锅带锅气」。

**做法（点对点）**

**第 1 步 · 热锅凉油防粘**
1. 山药含淀粉、容易粘锅，先空锅烧到微微冒烟再倒油、油热再下料——「热锅凉油」能让它不粘。

**第 2 步 · 山药两吃**
2. 脆山药（菜山药）适合清炒出爽脆；铁棍山药适合炒出粉糯口感——按想要的口感选品种。

**第 3 步 · 快炒出锅气**
3. 全程大火、动作快，出锅带「锅气」（高温 + 快炒带来的焦香），凉了就散，趁热吃。

**第 4 步 · 出锅前滴白醋**
4. 出锅前沿锅边滴几滴白醋，提亮颜色、去掉生味，山药更白更清爽。
