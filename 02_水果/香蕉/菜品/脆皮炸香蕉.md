# 脆皮炸香蕉

> 归属食材：[[香蕉]] ｜ 难度三档：初学 / 进阶 / 大厨

外皮金黄酥脆、内里香蕉软糯香甜，做法简单，趁热蘸炼乳、巧克力酱或沙拉酱都好吃。属性：热甜品 / 小吃。

> 计量参考：小勺 ≈ 5ml（茶匙），汤匙 ≈ 15ml，1 小勺盐 ≈ 5g、1 小勺糖 ≈ 5g。

---

## 初学版（目标：能做熟、不难吃）

**食材（2 人份）**

| 食材 | 用量 | 说明 |
|---|---|---|
| 香蕉 | 2 根 | 选熟透的（表皮有芝麻点、香气浓），但不能软烂 |
| 鸡蛋 | 1 个 | 打散成蛋液 |
| 玉米淀粉 | 约 2 汤匙 | 第一层裹粉 |
| 面包糠 | 约半碗 | 外层裹粉，炸出酥壳 |
| 食用油 | 约 300ml | 炸制用 |
| 炼乳 / 沙拉酱 | 适量 | 蘸食 |

**做法（点对点）**

**第 1 步 · 切香蕉**
1. 香蕉去皮，切成约 4~5cm 的段（也可以对半切后再各切两段），大小尽量一致。

**第 2 步 · 裹三层**
2. 香蕉段先滚一层干淀粉（薄薄一层，抖掉多余）。
3. 再裹一层蛋液。
4. 最后裹满面包糠，用手轻轻压一下让面包糠粘牢。

**第 3 步 · 热油**
5. 锅里倒油，中火烧到六成热（筷子伸进油里，周围快速冒小泡，约 160~170℃）。

**第 4 步 · 炸**
6. 放入裹好的香蕉段，转小火慢炸约 1 分钟。
7. 看到表面金黄就捞出。
8. 全部炸完后，把油温升高复炸 20 秒更脆。

**第 5 步 · 装盘**
9. 垫厨房纸吸掉多余油，趁热蘸炼乳或沙拉酱吃。

**新手翻车点**

- **面包糠脱落**：裹好后没压紧、或一下锅就被油冲散。每层裹完轻压一下，静置 1 分钟再下锅。
- **外焦内生 / 发苦**：油温太高。用中火烧到六成热后转小火慢炸，表面金黄即可捞出。
- **发酸**：选了没熟透的香蕉。要选熟透的，没熟透的香蕉炸出来会带酸味。
- **回软不脆**：炸好放太久。趁热吃最脆，或复炸一次恢复酥脆。

## 进阶版（关键技巧：三种裹法 / 油温 / 复炸 / 蘸酱）

在初学版基础上，掌握下面四条，外壳更酥、内里更软。

**做法（点对点）**

**第 1 步 · 三种裹法选一种**
1. **干淀粉 + 蛋液 + 面包糠**（最省事、最酥）：三层顺序不能乱，先粉后蛋再糠，面包糠才挂得住。
2. **面糊版**：面粉 : 淀粉 ≈ 3 : 1，加 1 小撮泡打粉，用清水调成酸奶状，静置 10 分钟后裹香蕉。
3. **脆皮浆版**：面粉 + 淀粉 + 少量吉士粉，加冰水调成略稠的糊，冰水面糊遇热更脆。

**第 2 步 · 控油温**
4. 油温控制在 170℃ 左右：太低温会吸油、外壳发软；太高温会外焦内生。
5. 没有温度计时，用「筷子伸进油里冒小泡」判断，或下一小块面糊试炸。

**第 3 步 · 复炸定型**
6. 第一遍炸到淡黄捞出。
7. 油温升到七八成热，复炸 20 秒。看到外壳更脆、内里更软 → 炸好了（复炸能逼出外壳水分）。

**第 4 步 · 蘸酱**
8. 经典：炼乳；进阶：巧克力酱 + 坚果碎、沙拉酱 / 番茄酱；更甜：淋蜂蜜 + 少许肉桂粉。

## 大厨版（专业细节与锅气）

追求「外壳酥脆不吸油、内里香蕉热乎软糯、有香气」，炸的火候和裹浆是重点。

**做法（点对点）**

**第 1 步 · 选蕉**
1. 选熟透香蕉（糖分高、香气足），但不要软烂。
2. 切段大小一致，保证受热均匀。

**第 2 步 · 脆皮浆配方**
3. 低筋面粉 + 淀粉 + 少量吉士粉（或泡打粉），用**冰水**调成略稠的糊——冰水面糊遇高温会更快形成酥脆外壳。

**第 3 步 · 下锅与冲油**
4. 裹好浆立即下锅，油温六成热。
5. 炸至外壳起硬壳捞出。
6. 复炸至金黄。
7. 出锅前几秒，用勺舀热油淋在香蕉表面（「冲油」），让外壳更酥、颜色更均匀。

**第 4 步 · 上桌与摆盘**
8. 尽快上桌，热的时候外壳最酥。
9. 可配一小碟炼乳和一小碟融化的巧克力酱，一甜一浓形成对比。
