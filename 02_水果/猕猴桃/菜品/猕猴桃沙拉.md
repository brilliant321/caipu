# 猕猴桃沙拉

> 归属食材：[[猕猴桃]] ｜ 难度三档：初学 / 进阶 / 大厨

清爽的水果凉菜沙拉，猕猴桃酸甜、酸奶香滑，搭配其他水果口感丰富，开胃解腻。以下按「初学 / 进阶 / 大厨」三档给出做法，难度和讲究逐级递增。

> 计量参考：小勺 ≈ 5ml（茶匙），汤匙 ≈ 15ml，1 小勺糖 ≈ 5g。

---

## 初学版（目标：能拌好、不烂不酸）

**食材（2 人份）**

| 食材 | 用量 | 说明 |
|---|---|---|
| 猕猴桃 | 2 个 | 挑稍硬（轻捏微弹）的，太软易烂 |
| 酸奶 | 100g | 原味或希腊酸奶，作酱汁基底 |
| 蜂蜜 | 1 小勺 | 调味，可选 |
| 香蕉 / 苹果 / 草莓 | 1 根 / 半个 / 适量 | 搭配水果（可选其一） |
| 坚果碎 / 葡萄干 | 1 小撮（可选） | 增口感 |

**做法（点对点）**

**第 1 步 · 判断生熟**
1. 猕猴桃轻捏：微软有弹性、能捏动但不变形 = 正好，可以用。
2. 硬邦邦 = 太生（酸、硬），先室温放几天催熟；一按一个坑 = 太熟（会烂、出水），别用。

**第 2 步 · 去皮切块**
3. 猕猴桃切掉两端，用勺子贴着皮内壁转一圈，把整颗果肉挖出来（或直接削皮）。
4. 切成约 2cm 的小块；搭配水果也切成差不多大小的块。看到大小差不多 → 切好了。

**第 3 步 · 调酱**
5. 酸奶加蜂蜜搅匀；喜欢酸就少放或不放蜂蜜。

**第 4 步 · 拌匀**
6. 所有水果块放大碗里，淋上酸奶酱。
7. 轻轻翻拌均匀，撒上坚果碎 / 葡萄干。**现拌现吃**最好，拌好别久放。

**新手翻车点**

- **猕猴桃太软**：切块变烂泥、出汁。选「微软偏硬」的，按下去能回弹的那种。
- **切块太大 / 不匀**：不好入口、酱拌不匀。都切成约 2cm 的小块。
- **酱太稀 / 太稠**：希腊酸奶浓、普通酸奶稀；太稀可少加或不加蜂蜜，太稠可加半勺酸奶搅开。
- **提前拌好放太久**：出水、氧化发软。临吃前再拌。
- **太酸**：猕猴桃偏酸时蜂蜜多放一点，或搭配香蕉、芒果增加甜度。

## 进阶版（关键技巧：生熟判断 / 搭配 / 酱汁变体）

在初学版基础上，掌握下面四条，口感更平衡、层次更丰富。

**做法（点对点）**

**第 1 步 · 生熟判断**
1. 用「软硬 + 香味」一起判断：闻起来有猕猴桃香 + 轻捏微软，才是最佳食用状态。
2. 冰箱里猕猴桃熟得慢，室温放 2~3 天即可变软。

**第 2 步 · 催熟**
3. 太生的猕猴桃和苹果 / 香蕉一起装进保鲜袋，常温放 2~3 天。它们会释放乙烯，帮猕猴桃加快成熟。

**第 3 步 · 搭配**
4. 甜酸互补：猕猴桃（酸）+ 香蕉 / 芒果 / 草莓（甜），整体不会太酸。
5. 口感层次：加坚果碎、燕麦脆，软滑中带脆。

**第 4 步 · 酱汁**
6. 酸奶 + 蜂蜜：清爽；酸奶 + 几滴柠檬汁：提亮、防氧化；希腊酸奶 + 蜂蜜：浓稠、能更好挂在水果上。

**第 5 步 · 防氧化**
7. 切好的猕猴桃淋几滴柠檬汁，或马上拌进酸奶，能延缓表面变褐。

## 大厨版（专业细节与出品）

追求「水果大小统一、酱汁浓稠挂果、酸甜清爽、卖相干净」。每一步都是细节。

**做法（点对点）**

**第 1 步 · 选果**
1. 沙拉用「硬熟」猕猴桃（略微软、微酸带甜），口感清爽；太软的虽甜，但切块易烂、易出水，拌出来糊成一团。

**第 2 步 · 切法统一**
2. 所有水果切成接近大小（约 2cm 方块），入口一致、拌酱均匀。
3. 猕猴桃用「两端切开 + 勺挖」法去皮最完整、不浪费果肉。

**第 3 步 · 酱汁调味**
4. 希腊酸奶 + 蜂蜜 + 几滴柠檬汁，调到浓稠能「挂」在水果上。
5. 喜欢更顺滑可加一点淡奶油，风味更高级。

**第 4 步 · 上桌前拌**
6. 酱汁临吃前才拌，避免出水。
7. 坚果碎最后撒，保持脆感。

**第 5 步 · 摆盘**
8. 盘底先铺一层酸奶酱，再堆水果块，点缀薄荷叶或坚果碎，视觉清爽。
