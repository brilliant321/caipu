# 红烧猪蹄

> 归属食材：[[猪蹄]] ｜ 难度三档：初学 / 进阶 / 大厨

猪蹄炖到软糯脱骨、胶质黏嘴，浓油赤酱、肥而不腻。成败关键就四条：毛去干净、冷水焯水去腥、糖色上色、小火炖够时间。

> 计量参考：小勺 ≈ 5ml（茶匙），汤匙 ≈ 15ml，1 小勺盐 ≈ 5g、1 小勺糖 ≈ 5g。

---

## 初学版（目标：能做熟、不难吃）

**食材（2~3 人份）**

| 食材 | 用量 | 说明 |
|---|---|---|
| 猪蹄 | 1 只（约 800g） | 让摊主剁成小块，省事又均匀 |
| 冰糖 | 约 15g | 炒糖色上色用 |
| 姜 | 5 片 | 去腥 |
| 大葱 | 1 段 | 去腥提香 |
| 八角 | 2 个 | 提香 |
| 香叶 | 2 片 | 提香 |
| 桂皮 | 1 小段 | 提香 |
| 干辣椒 | 2 个 | 可选，怕辣不放 |
| 料酒 | 2 汤匙（约 30ml） | 去腥 |
| 生抽 | 2 汤匙（约 30ml） | 提咸鲜 |
| 老抽 | 1 汤匙（约 15ml） | 上色 |
| 盐 | 约 1/2 小勺（2g） | 最后调味 |
| 食用油 | 1 汤匙（约 10ml） | 炒糖色用 |
| 开水 | 适量（没过猪蹄） | 一定用开水 |

**做法（点对点）**

**第 1 步 · 去毛**
1. 检查猪蹄块表面有没有残留的猪毛或黑毛根，有的话用镊子夹掉，或用燃气灶开小火把猪皮表面燎一下，再用刀刮洗干净。
2. 刮到表皮干净、没有黑毛根和焦糊 → 处理好了。（嫌麻烦就直接买摊主烧好皮的猪蹄）

**第 2 步 · 焯水去腥**
3. 猪蹄块 **冷水下锅**（焯水：肉类冷水下锅，让血水腥味慢慢被逼出来），加 2 片姜和 1 汤匙料酒，开中火加热。
4. 水开后撇去浮沫，再煮 3 分钟，捞出用 **温水** 冲洗干净、沥干。猪蹄表面不再有血沫 → 焯好了。

**第 3 步 · 炒糖色上色**
5. 锅烧热倒 1 汤匙油，转 **小火**，放冰糖慢慢炒，不停搅动。
6. 看到冰糖融化、颜色变成 **枣红色**、冒出细密小泡 → 立刻倒入猪蹄，快速翻炒，让每块都裹上糖色（糖色：把糖炒到焦化变红棕色，给肉上色提香，是红烧菜红亮颜色的来源）。

**第 4 步 · 调味炖煮**
7. 下姜、葱、八角、香叶、桂皮、干辣椒，炒香约 30 秒。
8. 淋入料酒、生抽、老抽，翻炒到猪蹄均匀上色。
9. 倒入 **开水** 没过猪蹄，大火烧开后转 **小火**，盖上盖子炖 1.5~2 小时，中间翻动一两次防粘底。

**第 5 步 · 收汁出锅**
10. 用筷子能轻松扎透猪蹄最厚的肉、皮软糯 → 炖烂了。
11. 开大火收汁（把多余水分煮掉，让汤汁变浓），不停翻动，收到汤汁浓稠、红亮地挂在猪蹄上。
12. 尝一口咸淡，偏淡补一点盐，关火出锅。

**新手翻车点**

- **有猪毛、腥味重**：没去毛或没烧皮。猪蹄的腥味一大半在皮和毛根里，去毛刮洗这一步不能省。
- **糖色炒糊发苦**：冰糖要用小火炒，一变成枣红色就下猪蹄，炒到冒黑烟、发黑就苦了，整锅都得重来。
- **加了冷水炖不烂**：炖肉一定加开水，冷水会让猪蹄瞬间收紧、发柴。
- **炖不烂**：时间不够或火太大。小火加盖炖 1.5 小时以上，用「筷子能轻松扎透」来判断。

## 进阶版（关键技巧：烧皮去腥 / 炒糖色枣红色 / 啤酒代水 / 收汁）

在初学版基础上，掌握下面几点，猪蹄更香、更软糯、颜色更亮。

**做法（点对点）**

**第 1 步 · 烧皮去腥（关键）**
1. 买猪蹄时让摊主用喷枪烧一下皮，或回家用燃气灶小火把表皮燎到微焦，再泡温水刮洗干净。
2. 烧皮能破坏猪皮里的汗腺（腥味的主要来源），成品几乎没有猪骚味。

**第 2 步 · 糖色炒到「枣红色细密小泡」**
3. 冰糖全程小火炒，观察三个变化：融化变透明 → 冒大泡 → 大泡变细密小泡、颜色变枣红色。
4. 在「枣红色、细密小泡」这一瞬间下猪蹄，早了不上色、晚了发苦。

**第 3 步 · 啤酒代替一半水**
5. 炖的时候用一半啤酒 + 一半开水，酒香能让猪蹄更软糯、更去腥，炖出来不腻。

**第 4 步 · 收汁浓稠挂勺**
6. 收汁时不停翻动，收到汤汁浓稠、能在勺背薄薄挂一层 → 关火。汤汁凉了会凝结成冻，更说明胶质炖出来了。

## 大厨版（专业细节与锅气）

追求「色泽红亮如琥珀、软糯脱骨、胶质黏嘴」。

**做法（点对点）**

**第 1 步 · 选前蹄**
1. 选 **猪前蹄**（前蹄肉多筋多、弯度大），比后蹄更软糯。
2. 太瘦的猪蹄炖不出「黏嘴」的胶质感，要带皮带筋。

**第 2 步 · 炒糖色用「余温法」更稳**
3. 锅底留少许油，小火把冰糖炒到枣红色细密小泡，**先关火**再下猪蹄，用余温快速翻匀上色，再开火继续炒。
4. 关火这一步给新手留出反应时间，不会因为手慢把糖色炒糊。

**第 3 步 · 高压锅省时 / 砂锅慢煨**
5. 赶时间用高压锅：上汽后压 25~30 分钟，猪蹄已软糯；不赶时间用砂锅小火煨 2 小时，胶质释放更充分、口感更糯。
6. 出锅前丢 1~2 片干山楂（可选）一起炖，去腻还让肉更易软烂。

**第 4 步 · 收汁出胶**
7. 捞出香料，大火收汁，边收边翻，收到汤汁浓稠、红亮挂肉、舀起来有胶质拉丝感。
8. 趁热吃——猪蹄凉了胶质凝固、口感打折；吃不完冷藏后汤汁会结冻，切片是另一种吃法。
