# 糖醋里脊

> 归属食材：[[猪肉]] ｜ 难度三档：初学 / 进阶 / 大厨

鲁菜经典，里脊挂糊炸脆后裹上酸甜糖醋汁，外酥里嫩、汁浓挂味。以下按「初学 / 进阶 / 大厨」三档给出做法，难度和讲究逐级递增。

> 计量参考：小勺 ≈ 5ml（茶匙），汤匙 ≈ 15ml，1 小勺盐 ≈ 5g、1 小勺糖 ≈ 5g。

---

## 初学版（目标：能做熟、不难吃）

**食材（2~3 人份）**

| 食材 | 用量 | 说明 |
|---|---|---|
| 猪里脊 | 约 300g | 切手指粗细的条 |
| 料酒 | 1 汤匙 | 腌肉去腥 |
| 盐 | 1/2 小勺 | 腌肉底味 |
| 白胡椒粉 | 1 小撮 | 去腥 |
| 鸡蛋 | 1 个 | 挂糊用（用蛋清更脆） |
| 玉米淀粉 | 约 60g | 挂糊主料 |
| 面粉 | 约 30g | 与淀粉混合，糊更挺 |
| 番茄酱 | 3 汤匙 | 糖醋汁底 |
| 白糖 | 2 汤匙 | 糖醋汁 |
| 白醋 | 2 汤匙 | 糖醋汁 |
| 清水 | 4 汤匙 | 糖醋汁 |
| 食用油 | 足量（约 500ml，炸用） | 能没过肉条 |

**做法（点对点，全程约 40 分钟）**

**第 1 步 · 切肉腌肉**
1. 里脊切成长约 5cm、粗细约 1cm 的条。
2. 加料酒、盐、白胡椒粉抓匀，腌 15 分钟。

**第 2 步 · 调糊**
3. 碗里放玉米淀粉和面粉，打入鸡蛋。
4. 慢慢加少量清水，搅成能挂在肉条上的浓稠糊（像稠酸奶）。

**第 3 步 · 炸第一遍**
5. 锅里倒足量油，烧到筷子伸进去周围冒小泡（约 160℃）。
6. 把肉条逐条裹糊下锅，炸到表面定型、微微发黄（约 2~3 分钟），捞出。

**第 4 步 · 调糖醋汁**
7. 小碗里放番茄酱、白糖、白醋、清水，搅匀。

**第 5 步 · 复炸 + 裹汁**
8. 把油烧得更热一点（约 200℃），肉条下锅复炸 30~40 秒到金黄酥脆，捞出。
9. 锅里留一点底油，倒入糖醋汁，小火熬到冒大泡、变浓稠。
10. 倒入炸好的里脊快速翻匀，让每根都裹上汁，出锅。

**新手翻车点**

- **外壳不脆、发软**：只炸了一遍，或炸好后放太久才裹汁。一定要复炸，且裹汁要快、趁热吃。
- **肉柴**：炸太久。第一遍炸到定型微黄就捞出，复炸只要 30~40 秒。
- **糖醋汁太稀、不挂味**：没熬到冒大泡就下肉。汁要小火熬浓稠再下里脊。
- **糊挂不住**：糊调得太稀，或肉条没擦干水分。糊要浓稠、肉条表面尽量干。

## 进阶版（关键技巧：糖醋汁比例 12345 / 挂糊炸脆 / 大火收汁）

在初学版基础上，掌握下面三条，成品质感会上一个台阶。

**做法（点对点）**

**第 1 步 · 糖醋汁比例——12345 口诀**
1. 万能糖醋汁可按「1 料酒 : 2 生抽 : 3 糖 : 4 醋 : 5 水」的比例调（以汤匙计，可按份等比例缩放）。例：1 汤匙料酒 + 2 汤匙生抽 + 3 汤匙糖 + 4 汤匙醋 + 5 汤匙水。
2. 里脊版想更红亮、更浓，可再加 1~2 汤匙番茄酱。
3. 勾一点水淀粉（半小勺淀粉 + 2 汤匙水）能让汁更挂肉。

**第 2 步 · 挂糊炸脆——外酥里嫩的关键**
4. 糊的配比：淀粉 : 面粉约 2 : 1，加蛋清或全蛋，调到「能挂住肉条、又不太厚」的稠度。
5. 炸两遍：第一遍低温（约 160℃）炸熟定型。
6. 第二遍高温（约 200℃）复炸 30~40 秒，把外壳炸酥、逼出多余油分。

**第 3 步 · 大火收汁——汁浓挂味**
7. 糖醋汁入锅后先中火熬到冒大泡。
8. 再倒入里脊转大火快速翻匀，让汁均匀裹住每根肉条，动作要快，否则外壳会回软。

## 大厨版（专业细节与锅气）

追求「外壳薄脆、肉嫩多汁、糖醋汁酸甜平衡、挂汁亮泽」。

**做法（点对点）**

**第 1 步 · 选肉与切条**
1. 里脊去净筋膜（筋膜炸后咬不动）。
2. 逆着纹路切成约 1cm 见方、5~6cm 长的条，长短粗细均匀，才能同时炸熟。

**第 2 步 · 脆糊的精配**
3. 传统脆糊可用「红薯淀粉 + 面粉 约 3 : 1」加少量泡打粉（约 2g），加水调成拉丝状。
4. 泡打粉让外壳更蓬松酥脆。
5. 挂糊前肉条吸干水分，糊要裹得薄而均匀。

**第 3 步 · 两段油温**
6. 第一段 160℃ 下锅，炸至定型、微黄捞出。
7. 第二段升到 200℃ 复炸 30~40 秒，外壳金黄酥脆、内部肉汁锁住。
8. 复炸时油温不够，外壳会吸油发腻。

**第 4 步 · 糖醋汁的平衡**
9. 老式糖醋里脊以糖、醋、酱油为主（不用番茄酱），讲究「酸甜平衡、色泽红亮」：醋可用米醋，糖用白糖或冰糖，最后勾薄芡让汁挂在肉上。
10. 家庭版可加番茄酱增色。
11. 汁熬到「鱼眼泡」、浓稠挂勺，再下里脊，大火翻匀即出锅，撒白芝麻。
