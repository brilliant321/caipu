# 糖醋排骨

> 归属食材：[[排骨]] ｜ 难度三档：初学 / 进阶 / 大厨

本帮 / 江浙家常经典，排骨烧得软糯脱骨，裹上酸甜糖醋汁，色泽红亮、酸甜适口。以下按「初学 / 进阶 / 大厨」三档给出做法，难度和讲究逐级递增。

> 计量参考：小勺 ≈ 5ml（茶匙），汤匙 ≈ 15ml，1 小勺盐 ≈ 5g、1 小勺糖 ≈ 5g。

---

## 初学版（目标：能做熟、不难吃）

**食材（2~3 人份）**

| 食材 | 用量 | 说明 |
|---|---|---|
| 猪肋排（小排） | 约 500g | 剁成 4~5cm 小段 |
| 姜 | 3~4 片 | 焯水用 |
| 小葱 | 2 根 | 焯水用 |
| 料酒 | 1 汤匙 | 12345 口诀之一 |
| 生抽 | 2 汤匙 | 12345 口诀之二 |
| 白糖 | 3 汤匙 | 12345 口诀之三 |
| 香醋（或米醋） | 4 汤匙 | 12345 口诀之四 |
| 清水 | 5 汤匙 | 12345 口诀之五 |
| 食用油 | 1 汤匙 | 炒排骨用 |

**做法（点对点，全程约 50 分钟）**

**第 1 步 · 焯水**
1. 排骨冷水下锅，加姜片、葱结。
2. 大火烧开，撇去浮沫。
3. 再煮 2 分钟 → 血沫浮起、排骨变色，捞出。
4. 用温水冲净、沥干（不要用冷水冲，肉会收紧）。

**第 2 步 · 炒排骨**
5. 锅里放 1 汤匙油，下排骨中火翻炒 2~3 分钟。
6. 炒到表面微微发黄、逼出香味 → 进行下一步。

**第 3 步 · 焖烧**
7. 按「12345 口诀」加入 1 汤匙料酒、2 汤匙生抽、3 汤匙白糖、4 汤匙醋、5 汤匙清水，翻匀。
8. 大火烧开后转小火，盖盖焖 30~40 分钟，中间翻动一两次。
9. 直到排骨软烂（用筷子能轻松扎透）→ 进行下一步。

**第 4 步 · 收汁出锅**
10. 开大火收汁，不停翻动，让汤汁变浓、红亮，均匀裹住排骨。
11. 收干到快没汤时 → 关火出锅。

**新手翻车点**

- **排骨发柴**：焯水后没用温水冲，或焖的时间不够。冷水冲会让肉收紧变柴；焖到筷子能轻松扎透再收汁。
- **汁不收、不挂味**：最后没收汁就出锅。一定要开大火，把汁收到浓稠裹住排骨。
- **发苦**：没用口诀、糖炒焦了。初学版不用单独炒糖色，直接按 12345 放糖，安全不易苦。
- **太酸或太甜**：12345 口诀里的糖醋可按口味微调，但别一次加太多，收汁后先尝再补。

## 进阶版（关键技巧：糖醋汁 12345 / 炒糖色 / 大火收汁）

在初学版基础上，掌握下面三条，成品质感会上一个台阶。

**做法（点对点）**

**第 1 步 · 糖醋汁 12345 口诀——酸甜平衡**
1. 按「1 料酒 : 2 生抽 : 3 糖 : 4 醋 : 5 水」以汤匙计，可按排骨量等比例缩放。
2. 记住口诀的意义：糖比醋略少、液体总量刚好够焖烧，最后收汁自然形成亮红色糖醋汁 → 心里有数再动手。

**第 2 步 · 炒糖色——色泽红亮的来源**
3. 锅里放 2 汤匙冰糖或白糖，加少量油，小火慢慢炒化。
4. 看颜色从白 → 黄 → 琥珀色 → 立刻下排骨，快速翻炒上色。
5. 糖色让成品红亮，比只靠生抽好看；务必小火、看颜色，火候稍过就发苦。

**第 3 步 · 大火收汁——汁浓亮、挂肉**
6. 焖软后开大火，边收边翻，让糖和醋在高温下浓缩、产生光泽。
7. 收汁时可再补半汤匙醋（醋受热挥发快，最后补一点提酸香）。

## 大厨版（专业细节与锅气）

追求「色泽红亮、软糯脱骨、酸甜适口、汁浓挂骨」。

**做法（点对点）**

**第 1 步 · 选肉与预处理**
1. 选肋排中段（带一点肥肉），剁成 4~5cm 小段。
2. 焯水要「冷水下锅」，煮出血沫后捞出用温水洗净——热水下锅血沫会锁在肉里。

**第 2 步 · 炒糖色的火候**
3. 冰糖下锅小火慢炒，不停搅动。
4. 颜色到「琥珀色、冒细密小泡」→ 立刻下排骨（这是糖色最佳时机，再深就苦）。
5. 下排骨时注意防溅。

**第 3 步 · 醋分两次放——酸香有层次**
6. 第一次按口诀放 4 汤匙醋焖烧，让排骨吃进酸香。
7. 收汁前再补 1/2~1 汤匙醋，补回挥发掉的酸味，成品酸香更立体。

**第 4 步 · 收汁的成品标准**
8. 大火收汁到汤汁能「挂在排骨上、锅底几乎无流动汤汁」，色泽红亮、油润。
9. 出锅撒白芝麻和葱花。这道菜要趁热吃，凉了糖醋汁会变黏。
