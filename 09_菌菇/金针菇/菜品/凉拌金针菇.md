# 凉拌金针菇

> 归属食材：[[金针菇]] ｜ 难度三档：初学 / 进阶 / 大厨

金针菇脆嫩爽滑，吸满酸辣料汁，热量低又开胃，是几分钟就能搞定的快手凉菜。关键是剪根洗净、焯熟和「攥干水」。

> 计量参考：小勺 ≈ 5ml（茶匙），汤匙 ≈ 15ml，1 小勺盐 ≈ 5g、1 小勺糖 ≈ 5g。

---

## 初学版（目标：能焯熟、酸辣开胃）

**食材（2 人份）**

| 食材 | 用量 | 说明 |
|---|---|---|
| 金针菇 | 1 把（约 200g） | 剪根、洗净 |
| 蒜 | 3 瓣 | 切末 |
| 小米辣 | 1~2 个（可选） | 切圈 |
| 香菜 | 1 小把（可选） | 切段 |
| 生抽 | 2 汤匙 | |
| 香醋 | 1 汤匙 | |
| 白糖 | 1 小勺 | |
| 香油 | 1 小勺 | |
| 辣椒油 | 1 小勺（可选） | 不吃辣可不放 |

**做法（点对点）**

**第 1 步 · 处理**
1. 金针菇切掉根部带泥的一截（约 1~2cm）。
2. 撕成小撮，在流水下冲干净。

**第 2 步 · 焯水**
3. 水烧开后下金针菇，煮约 2~3 分钟（金针菇一定要煮熟）。
4. 捞出过凉水。

**第 3 步 · 攥干水（关键）**
5. 用手把金针菇里的水攥干（金针菇特别吸水，不攥干料汁进不去、味道淡）。

**第 4 步 · 调汁**
6. 碗里放蒜末、小米辣、生抽、香醋、白糖、香油、辣椒油，搅匀。

**第 5 步 · 拌匀**
7. 金针菇放进大碗，倒料汁翻拌，撒香菜。
8. 腌 3~5 分钟更入味。

**新手翻车点**

- **金针菇咬不动 / 带土**：根没剪干净或没煮熟。根部剪掉 1~2cm，水开煮 2~3 分钟。
- **味道淡**：没攥干水。金针菇攥干再拌，料汁才挂得住。
- **煮过头发烂**：煮太久。金针菇易熟，2~3 分钟就够，捞出立刻过凉水。
- **太辣**：小米辣和辣椒油先少放，拌好尝过再加。

## 进阶版（关键技巧：清洗 / 焯水 / 料汁 / 配菜）

在初学版基础上，掌握下面四条，成品质感会上一个台阶。

**做法（点对点）**

**第 1 步 · 清洗**
1. 剪根后把金针菇撕成小撮，放盐水里泡 5 分钟再冲洗，更干净。
2. 别整把一起冲，根部藏泥。

**第 2 步 · 焯水**
3. 水开加一点盐，下金针菇煮 2~3 分钟。
4. 要脆嫩口感就煮 1~2 分钟，要更熟软就煮 3 分钟。
5. 捞出过凉水锁住脆度。

**第 3 步 · 料汁**
6. 蒜末 + 小米辣 + 白芝麻 + 辣椒面，淋热油激香。
7. 再加生抽、醋、糖、蚝油、香油，酸辣咸香层次足。

**第 4 步 · 配菜**
8. 黄瓜丝、胡萝卜丝（焯熟）、火腿丝、黑木耳都可以加，颜色口感更丰富。
9. 冷藏 10 分钟风味更佳。

## 大厨版（专业细节）

**做法（点对点）**

**第 1 步 · 处理到位**
1. 金针菇剪根后撕成均匀小撮。
2. 焯水时散开放，受热均匀、口感一致。

**第 2 步 · 焯水控时**
3. 水要大开再下锅，煮 1~2 分钟（刚熟透）。
4. 立刻捞出投冰水，口感最脆嫩——这是饭店凉菜「脆」的秘诀。

**第 3 步 · 料油提香**
5. 冷油下花椒、干辣椒段小火炸香，捞出料渣。
6. 热油泼在蒜末辣椒面上。
7. 再加生抽、香醋、糖、一点花椒油和熟芝麻，麻辣鲜香。

**第 4 步 · 拌后静置**
8. 拌好冷藏 10 分钟让味道进去。
9. 上桌前再淋一点料油、撒香菜，卖相和香气都更好。
