# 姜

> 去腥暖胃的「万能去腥姜」，老姜调味去腥、嫩姜当菜吃，烂姜不能吃。

## 功能作用

- **去腥提鲜**：姜含姜辣素和挥发油，能压住鱼、肉、海鲜的腥味，还能中和鱼蟹的寒性（姜性热）。清蒸鱼、炖肉放姜片，是标配。
- **暖胃散寒**：性辛温，能刺激消化液分泌、促进血液循环，天冷煲汤、喝姜茶暖胃暖身。
- **提香开胃**：炒菜用姜片/姜末爆香，底味更香；糖醋鱼用姜末，去腥又提味。
- **老姜 vs 嫩姜**：老姜（色深、纤维多、味辣）适合调味、去腥、煮姜汤；嫩姜又叫仔姜（色浅、肉嫩多汁、辣味轻），适合炒菜、凉拌、做酱菜。

## 实际应用场景

- **炖肉 / 炖汤**：清炖鸡、排骨汤、羊肉汤，姜片冷水下锅，久炖出香去腥。
- **蒸鱼 / 海鲜**：清蒸鱼、蒸螃蟹，鱼身铺姜片/姜丝，出锅蘸姜醋汁。
- **炒菜爆香**：姜片或姜末热油爆香，再下主料，家常炒肉、炒青菜通用。
- **糖醋 / 红烧**：糖醋鱼、红烧鱼用姜末调汁去腥；红烧肉放姜片。
- **甜品 / 饮品**：姜汁撞奶、姜枣茶、红糖姜水（见 [[姜汁撞奶]]）。

## 常见搭配

- **姜 + 葱 + 蒜** → 炒菜爆香「三件套」。
- **姜 + 醋** → 蘸海鲜的姜醋汁，去腥又解寒。
- **姜 + 红糖 / 红枣** → 红糖姜水、姜枣茶，暖身驱寒。

## 用量与禁忌

- 家常炒菜/炖肉放**2~4 片（约 3~10 克）**就够，去腥靠的是香味不是量；放多会辣、抢味。
- 姜片可久煮；炒菜时别炒糊，糊了发苦。
- **烂姜千万别吃**：腐烂生姜会产生黄樟素（有致癌风险），「烂姜不烂味」是错的，烂了整块丢。
- 禁忌：性辛温助火，上火、阴虚内热、嗓子疼、痔疮的人少吃；「晚上少吃姜」是传统说法（晚吃姜易燥）。

## 选购与保存

- **选购**：挑块体饱满、皮色正常、无烂顶无黑心、不发软不长霉的；表皮起皱、干瘪的是陈姜。
- **保存**：生姜喜阴湿、怕干怕冻（适宜 12~15℃），放阴凉处或埋湿沙里；切开没用的，泡清水冷藏或打成姜汁密封冷藏，能用 3~4 周。
