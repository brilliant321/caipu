# 调味香料

> 「调味香料」类原料目录：香辛料 + 基础调味料，共 29 种。每种点进去是详细说明（功能作用 / 实际应用场景 / 常见搭配 / 用量与禁忌 / 选购与保存）。

## 香辛料（20 种）

| 香料 | 一句话定位 |
|---|---|
| [[八角]] | 卤味红烧那股「甜香」，去腥增香解腻的主力 |
| [[葱]] | 去腥提香的「底香」，葱白爆香、葱叶点缀 |
| [[姜]] | 去腥暖胃，老姜去腥、嫩姜可生吃 |
| [[蒜]] | 提香杀菌，生熟两用 |
| [[辣椒]] | 加辣增香上色，辣味来自辣椒素 |
| [[花椒]] | 川菜「麻」的来源，去腥压膻 |
| [[桂皮]] | 去腥解腻增甜，卤味红烧必备 |
| [[香菜]] | 提香解腻增色，出锅前放 |
| [[孜然]] | 烧烤灵魂，去膻增香 |
| [[胡椒]] | 黑重香、白提鲜，黑配红肉白配白肉 |
| [[香叶]] | 去腥增香的「底香担当」，耐煮 |
| [[丁香]] | 香味霸道的「透骨香」，用量极少 |
| [[草果]] | 炖羊肉、卤味去膻利器 |
| [[小茴香]] | 去膻增香、助消化，五香粉主料 |
| [[白芷]] | 卤水「香料之花」，去腥强、出香慢 |
| [[陈皮]] | 橘皮陈放，去腥解腻、理气 |
| [[豆蔻]] | 白豆蔻去腥 / 草豆蔻去膻 / 肉豆蔻提香 |
| [[砂仁]] | 去腥除腻，宜后放 |
| [[甘草]] | 卤味「调和之王」，回甘压苦 |
| [[山奈]] | 沙姜，干鲜两用，沙姜鸡灵魂 |

## 基础调味料（9 种）

| 调味料 | 一句话定位 |
|---|---|
| [[酱油]] | 生抽提鲜、老抽上色 |
| [[醋]] | 陈醋耐久煮、香醋凉拌、米醋百搭、白醋保色 |
| [[料酒]] | 去腥增香，急火沿锅边淋 |
| [[糖]] | 白糖提鲜、冰糖上色、红糖风味 |
| [[盐]] | 百味之本，每日 ≤5 克 |
| [[蚝油]] | 生蚝提鲜「海底牛奶」，出锅前放 |
| [[味精]] | 味精/鸡精，出锅前放 |
| [[香油]] | 芝麻油，忌高温，凉拌最佳 |
| [[淀粉]] | 玉米嫩肉 / 土豆勾芡 / 红薯炸酥 / 木薯甜品 |
