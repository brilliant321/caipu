# 蒜

> 杀菌提香的「天然抗生素」，生蒜辛辣、熟蒜香软，蒜蓉酱拌啥都香。

## 功能作用

- **增香提味**：蒜含大蒜素等含硫化合物，切碎或捣碎后释放出浓烈蒜香，是炒菜、蘸料、凉拌的「香底」。炒菜热油爆蒜末，香飘满屋。
- **杀菌防腐**：大蒜素有广谱抗菌作用，被称为「天然抗生素」。凉拌菜放蒜泥，既提味又「消毒」。
- **去腥解腻**：烧鱼煮肉放蒜，解腥助消化；蒜蓉配海鲜（蒜蓉粉丝蒸虾）去腥增香。
- **生熟两种用法**：生蒜辛辣刺激、杀菌更强，适合捣成蒜泥蘸料；熟蒜（炒过/炸过）辛味变温和、香气更香，适合炒菜炖菜。

## 实际应用场景

- **炒菜爆香**：蒜末/蒜片热油爆香，再下菜，家常炒青菜、炒肉通用（蒜末别炒糊，糊了发苦）。
- **蘸料 / 凉拌**：蒜泥加醋、生抽、香油，是饺子蘸料、拍黄瓜、凉拌菜的标配。
- **海鲜 / 蒸菜**：蒜蓉粉丝蒸虾、蒜蓉蒸扇贝、蒜蓉生蚝，蒜蓉铺面蒸，去腥增香。
- **炖肉 / 烧菜**：红烧肉、炖鱼、烧茄子放整瓣蒜，久炖蒜香融入汤汁。
- **蒜蓉酱**：大量蒜剁成蓉，做成蒜蓉酱拌面拌菜（见 [[蒜蓉酱]]）。

## 常见搭配

- **蒜 + 醋** → 饺子蘸料、凉拌菜的灵魂组合。
- **蒜 + 辣椒油 + 香油** → 川味蘸水、火锅油碟。
- **蒜 + 葱 + 姜** → 炒菜爆香「三件套」。

## 用量与禁忌

- 家常炒菜 2~3 瓣切末就够；做蒜蓉菜、蒜蓉酱可以多放。放多（尤其生蒜）会辛辣刺激胃、口气重。
- **想杀菌提香，生蒜捣碎后静置 10~15 分钟再吃/再用**，大蒜素才充分生成；但生蒜别空腹吃。
- 禁忌：阴虚火旺、有眼疾、胃溃疡/十二指肠溃疡的人少吃生蒜；空腹、服药期间谨慎。「蒜是发物」的说法因人而异，拿不准就少吃。

## 选购与保存

- **选购**：挑蒜头饱满、蒜瓣洁白紧实、包裹完整、干爽无虫、不发芽不开裂的，掂着沉；紫皮蒜常被推荐（香气更浓）。
- **保存**：挂通风处或放阴凉干燥处，能存几个月；防发芽就别放冰箱冷藏太久（湿冷易发芽），也别和土豆放一起。剥好的蒜可盐腌、油浸防坏；蒜蓉酱密封冷藏尽快用完。
