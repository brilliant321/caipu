# 老醋花生

> 归属食材：[[花生]] ｜ 难度三档：初学 / 进阶 / 大厨

花生酥脆、糖醋汁酸甜醇厚，配洋葱青椒清爽解腻，是经典下酒凉菜。属性：凉菜（下酒菜）。

> 计量参考：小勺 ≈ 5ml（茶匙），汤匙 ≈ 15ml，1 小勺盐 ≈ 5g、1 小勺糖 ≈ 5g。

---

## 初学版（目标：能做熟、不难吃）

**食材（2 人份）**

| 食材 | 用量 | 说明 |
|---|---|---|
| 花生米 | 200g | 选大小均匀的 |
| 陈醋 | 3 汤匙（约 45ml） | 老醋香浓 |
| 白糖 | 2 汤匙（约 30g） | 酸甜比可调 |
| 生抽 | 1 汤匙 | 提鲜 |
| 盐 | 1/4 小勺 | 调味 |
| 洋葱 | 1/4 个 | 切小丁 |
| 青椒（或黄瓜） | 半个 | 切小丁 |
| 淀粉 | 1 小勺 | 勾芡让汁挂住（可选） |
| 食用油 | 约 2 汤匙 | 炸花生用 |

**做法（点对点）**

**第 1 步 · 炸花生**
1. 冷锅冷油下花生米，小火慢慢加热，不停翻炒约 3~5 分钟。
2. 听到"噼啪"声、花生皮变深、有香味 → 立刻关火捞出（余温会继续烘）。
3. 捞出摊开晾凉，凉透才脆。

**第 2 步 · 调糖醋汁**
4. 小碗里陈醋、白糖、生抽、盐拌匀。
5. 想汁浓稠挂住，就加半小勺淀粉调成水淀粉。

**第 3 步 · 熬汁**
6. 把糖醋汁倒进锅里，小火熬到糖完全融化、汁微微浓稠（约 1~2 分钟），关火晾凉。

**第 4 步 · 拌**
7. 花生米彻底晾凉后，加洋葱丁、青椒丁。
8. 倒晾凉的糖醋汁拌匀，腌 5~10 分钟更入味。

**新手翻车点**

- **花生炸糊**：火太大。全程小火，变色就关火，余温会继续加热。
- **花生不脆**：没彻底晾凉就拌汁。炸好一定摊开晾透再拌。
- **太酸 / 太甜**：先按比例调，熬汁前尝一下，酸多放糖、甜多放醋。
- **汁太稀挂不住**：想挂汁就加淀粉勾芡，或熬久一点。

## 进阶版（关键技巧：酥脆 / 糖醋比 / 免油炸）

在初学版基础上掌握下面四条，口感和味道更好。

**做法（点对点）**

**第 1 步 · 酥脆更持久**
1. 炸好的花生趁热喷少许高度白酒（或白酒），拌散晾凉，凉后更脆、不易回软。

**第 2 步 · 调糖醋比例**
2. 按经典约醋 : 糖 = 3 : 2（也可 1 : 1）调，按口味微调；加一点蚝油更鲜。

**第 3 步 · 免油炸**
3. 烤箱 150℃ 烤 15~20 分钟、中途翻面，或空气炸锅 160℃ 炸 10~12 分钟，少油同样酥脆。

**第 4 步 · 吃前再拌**
4. 糖醋汁熬好冷藏，吃前再把汁和花生、配菜拌在一起，花生更脆不回软。

## 大厨版（专业细节与锅气）

**做法（点对点）**

**第 1 步 · 炸花生**
1. 冷锅冷油下花生，全程小火。
2. 听到密集"噼啪"声 → 离火，靠锅底余温烘到金黄，最不容易糊。

**第 2 步 · 勾芡挂汁**
3. 糖醋汁熬到"挂勺"（勺子蘸汁能挂一层）→ 关火，晾凉后能均匀裹住每颗花生。

**第 3 步 · 配菜切细丁**
4. 洋葱、青椒切成约 0.5cm 的小丁，与花生大小相称，一勺入口口感统一。

**第 4 步 · 点缀**
5. 拌好前点几滴香油，撒一点香菜段提香，装盘后现吃最脆。
